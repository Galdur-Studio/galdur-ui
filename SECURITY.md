# Security policy

## Supported versions

Only the latest release of Galdur UI receives fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Write to
[contact@galdurstudio.com](mailto:contact@galdurstudio.com) with the Galdur UI version, the loader and
Minecraft version, and the steps to reproduce. We'll reply by email, and we'll publish a fixed release
before the problem is made public.
